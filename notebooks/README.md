### Notebook directory

* `Test.ipynb` : This is a test notebook to demonstrate how to use this repository.

* `AugImg_CLAHE_HP.ipynb` : Compares CLAHE and high-pass filtering on NISAR tiles. The final cell
  needs the comparison frame
  `NISAR_L2_PR_GCOV_024_077_A_140_4005_SHSH_A_20260701T135211_20260701T135247_P05023_N_F_J_001.h5`.
  It must be available offline in Box (right-click, Make Available Offline) before you run that
  cell. To use another frame, change `FRAME_NAME` (the start of the file name) in that cell.
